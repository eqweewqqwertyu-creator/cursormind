# 文件整理术

整理用户指定的文件夹。核心纪律：先看全、再预演、经确认、才动手。

## 流程
1. **清点**：列出目标目录全部内容（文件数、类型分布、大小、最后修改时间）。超过 200 个文件时先统计类型分布，不要逐个枚举。
2. **提分类方案**：按「用户任务原话里的意图」优先，其次按扩展名/日期/项目归属。方案要给出目录树预览（建哪几个文件夹、每类预计多少个文件）。
3. **预演确认**：把方案写进答复（「我准备这样分：文档→doc/，图片→img/…，共 N 个文件」），等用户确认。整理用户已有文件属于修改类操作，不许跳过这一步。
4. **执行**：确认后用 pwsh 批量移动（`Move-Item` 按扩展名过滤），一次脚本完成，不逐文件调工具。
5. **报告**：答复里给出前后对比（原 N 个散文件 → 现 M 个分类目录），并列出无法归类的遗留项。

## 常见套路
- 重命名批量：`Get-ChildItem *.jpg | Rename-Item -NewName { "照片_" + $_.LastWriteTime.ToString("yyyyMMdd_HHmmss") + $_.Extension }`，先 `-WhatIf` 预演。
- 去重：按文件哈希分组（`Get-FileHash`），列出重复清单让用户挑，不擅自删。
- 「按日期归档」默认按月分（2026-10/），别按天碎成几百个目录。

## 红线
- 整理 C:\Windows、Program Files 等系统目录：直接拒绝并说明风险。
- exe/msi/安装包默认归到「安装包/」并提醒用户确认是否删除，不代删。
- 移动前确认目标子目录不重名冲突，有冲突加序号后缀。
